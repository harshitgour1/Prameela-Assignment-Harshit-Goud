# AI Tool Usage

As requested, this document outlines how AI-assisted development tools were used to build this application.

### 1. Which AI tools were used

- **Antigravity** (Google DeepMind's Agentic Coding Assistant)
- **Claude** (Logic and flow explanations)
- **ChatGPT / Codex** (for general logic exploration)

### 2. Where AI was used

AI was used across the entire stack (Frontend and Backend) for:
- Initial project scaffolding and boilerplate (NestJS setup, Prisma schemas, Next.js App Router structure).
- Next.js component generation and UI implementation.
- Debugging and troubleshooting (e.g., tricky UI edge cases like hydration mismatches).
- Test setup, test cases, and CI workflow configuration.
- Docker containerization configuration.

### 3. Why AI was used

- **Velocity:** To scaffold repetitive boilerplate significantly faster than writing it from scratch and to explore structural solutions rapidly.
- **UI Consistency:** To correctly implement a fully semantic Tailwind CSS Dark/Light mode using standard design tokens, avoiding manual color-picking.
- **Problem Solving:** To rapidly debug responsive behaviors, TypeScript/ESLint strictness issues, and CI failures.

*Note: AI was treated as an assistant. All generated code was thoroughly reviewed, and final decisions were made based on project architecture and requirements.*

### 4. Example prompts

- *"Initialize a new Next.js project with Tailwind CSS and shadcn/ui components."*
- *"Create a NestJS backend with Prisma. We need endpoints for creating, listing, searching, and deleting companies."*
- *"Optimize and make the Mobile UI proper and nice. The current table overflows horizontally."*
- *"Check the errors and fix. [browser] A tree hydrated but some attributes of the server rendered HTML didn't match the client properties... fdprocessedid=\"6ho5tm\""*
- *"Add a proper light and dark mode toggle with proper verification and tests."*
- *"Review the CI workflow and make sure typecheck, lint, tests, E2E tests and builds are properly enforced."*

### 5. Code that was kept

AI-assisted code was retained where it perfectly matched the requirements and passed strict architectural review. Examples include:
- The vast majority of the NestJS service logic and API implementation.
- Prisma queries (optimized for searching, paginating, and sorting).
- The Tailwind utility classes for the responsive Card View on mobile (which implemented the industry standard flawlessly).
- `docker-compose.yml` and `Dockerfile` configurations.
- Jest/Vitest test configurations and initial test cases.

### 6. Code that was changed or rejected

Not all generated code was accepted as-is.
- **Rejected:** An initial mobile implementation attempted to solve the desktop table overflow by simply hiding columns (`hidden sm:table-cell`). I rejected this approach and implemented a dedicated mobile Card Layout instead for a true premium experience.
- **Modified:** The AI-generated `Select` component from Shadcn/Base UI defaulted to "item-aligned" positioning, which looked awkward. I manually adjusted it to use `position="popper"` with proper alignment.
- **Modified:** The default dark mode colors generated by the AI were a bit harsh. I manually tweaked the `--primary` oklch color variables in `globals.css` to be a softer, subtle brand blue that looked visually stunning in both light and dark modes.
- **Refined:** During the final production-quality pass, generated code was heavily corrected for issues such as unnecessary `any` usage, unused variables, deterministic secondary-key pagination, and strict test/CI pipeline enforcement.

### 7. Verification

AI-generated code was treated as a starting point rather than automatically correct. The final implementation was rigorously verified using:
- TypeScript strict typechecking
- ESLint (enforced 0 warnings/errors)
- Backend unit and true Postgres API E2E tests
- Frontend React component tests
- Production optimized Turbopack builds
- Manual UI, accessibility, and responsive testing

The final code and engineering decisions remain my responsibility.
